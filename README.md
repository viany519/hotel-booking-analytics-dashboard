# Hotel Booking Analytics Dashboard

An interactive web dashboard for visualizing hotel booking cancellation patterns based on exploratory data analysis (EDA).

This project presents analytical insights from hotel reservation data through an interactive dashboard interface, helping users understand customer behavior, booking characteristics, and factors influencing reservation cancellations.

## 🚀 Live Demo

🔗 https://hotel-booking-analytics-dashboard.vercel.app

---

## 📌 Project Overview

Hotel Booking Analytics Dashboard is a data visualization project that transforms hotel reservation analysis results into an interactive web application.

The dashboard provides insights about:

- Customer booking behavior
- Cancellation patterns
- Lead time impact
- Market segment performance
- Room price categories
- Seasonal booking trends
- Special request behavior

The project focuses on presenting data-driven insights in a clear and interactive way for business understanding and decision-making.
